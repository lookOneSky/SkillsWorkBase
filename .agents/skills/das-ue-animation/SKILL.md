# Unreal 动作与动画

- 涉及 UE 动作制作、生成或修改时，必须先检索并参考动捕库，依据与目标动作匹配的动作捕捉片段生成或调整动画，不得跳过动捕参考凭空制作。
- 优先使用用户指定或工程已有的动捕库；未指定时查找当前可访问的动捕资源。无法访问动捕库或找不到匹配素材时，先向用户确认可用来源或请求提供素材，再继续生成或修改动画。
- 结合目标角色骨骼与动作要求，进行必要的重定向、节奏、幅度和根运动调整，保留参考动作的重心变化及接触关系。
- 完成前在目标角色上检查脚滑、穿插和动作衔接；交付时注明参考的动捕库来源、片段名称或路径，以及实际调整内容。
