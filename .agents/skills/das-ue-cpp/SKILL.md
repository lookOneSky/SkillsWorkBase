- Plan 以代码为主，只保留理解当前变更所需的最少文字。
- 只展示当前需要新增或修改的代码，不展示未变化的代码或完整文件。
- 所有 C++ 代码使用带 `cpp` 语言标识的 Markdown 围栏代码块。
- 代码该换行时换行，不为减少行数压缩格式。
- 临时变量名使用“类型前缀 + 驼峰名称”：小写首字母表示类型，后续名称使用大驼峰。
