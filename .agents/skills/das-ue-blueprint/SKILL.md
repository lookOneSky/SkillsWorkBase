# UE 蓝图手动修改规范

- 涉及 UE 蓝图代码或逻辑的修改时，只说明如何修改，由用户手动操作，不直接修改蓝图。
- 不通过编辑器自动化、MCP、脚本或直接写入资产文件等方式代替用户修改蓝图；可以只读查看现有蓝图以确定修改方案。
- 说明需要修改的蓝图资产路径，以及对应的事件图表、函数、宏或事件；按实际改动列出要新增、删除或调整的节点、变量、引脚类型、参数和默认值。
- 按操作顺序说明节点连接：明确源节点与输出引脚、目标节点与输入引脚，并区分执行线和数据线；只展示本次需要改动的部分。
- 代码变更需要同步调整蓝图时，说明受影响的蓝图及具体同步步骤。
- 缺少定位蓝图或确定节点连接所必需的信息时，先查看可用资料，仍不足再向用户询问，不猜测现有蓝图结构。
- 最后给出用户手动编译、保存及验证蓝图行为的方法；未经实际验证，不声称蓝图已经修改或验证通过。
